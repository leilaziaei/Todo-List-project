# Advanced Todo App (Vanilla JavaScript)

A fully modular Todo application built with Vanilla JavaScript.
This project focuses on clean architecture, separation of concerns,
and state management without using any framework.

## Features
- Add, delete and complete tasks
- Filter, search and sort tasks
- Dark mode with persistence
- Export tasks to PDF and Excel
- LocalStorage persistence
- Modular JavaScript architecture

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES Modules)
- LocalStorage
- jsPDF
- ExcelJS

## Project Structure

src/
├─ storage.js    # State management & LocalStorage
├─ render.js     # DOM rendering logic
├─ filter.js     # Filtering and sorting logic
├─ tasks.js      # Task factory
├─ darkMode.js   # Dark mode logic
├─ export.js     # PDF & Excel export
└─ main.js       # App entry point & event handling

## How to Run

1. Clone the repository
2. Open the project using Live Server
3. Enjoy 🚀

## Notes

This project was created to practice modular JavaScript architecture
and state management without using frameworks.
